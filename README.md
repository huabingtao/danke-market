# 🎮 欢乐牧场价格看板 (多人云端部署版)

这是一个专门面向《弹壳特攻队》欢乐牧场活动的价格看板。经过改造，它已支持**多人并发自主填报**与**主播/观众权限隔离**，可以直接部署到公网服务器。

---

## 🛠️ 项目结构与设计

1. **前端 (React + Vite)**：
   * 自动分配随机的 `ownerId` (UUID) 存在浏览器本地。
   * 观众仅能编辑或删除**自己**提交的价格行（其他行不可修改、不可删除）。
   * 主播（超级管理员）使用带密钥的链接进入后，拥有全局管理权，可以一键清空、排序或删除任何行。
2. **后端 (Node.js + Express)**：
   * 采用增量 API (`/api/add`, `/api/update`, `/api/delete`)，规避多人并发时的写入覆盖冲突。
   * 每天 **18:00** 自动重置并清空所有价格数据（可在配置中自定义时区）。
   * 内存缓存 + 文件持久化，超高并发读取性能。

## ⚙️ 配置指南

在项目根目录下，你可以找到或新建 `config.json` 文件进行服务器配置：

```json
{
  "port": 8080,
  "adminPassword": "你的管理员密码",
  "timezone": "Asia/Shanghai"
}
```

* `port`: 服务对外监听的端口（默认 8080）。
* `adminPassword`: 主播登录管理员权限时需要输入的密码。
* `timezone`: 时区（默认 `Asia/Shanghai`），用于计算每天 18:00 的自动清空重置。

## 🚀 部署到云服务器

请按照以下步骤，在你的腾讯云、阿里云或其他 Linux 云服务器上进行部署：

### 第一步：准备 Node.js 环境
如果服务器还没有 Node.js，请先安装。推荐使用 Node.js v18 或更高版本。
可以使用 NVM（Node Version Manager）或直接通过系统包管理器安装。

### 第二步：上传项目并安装依赖
1. 将当前项目打包上传到服务器。
2. 进入项目根目录，运行命令安装所需依赖：
   ```bash
   npm install
   ```

### 第三步：编译前端打包
运行以下命令编译打包前端 React 静态页面：
```bash
npm run build
```
编译成功后，会在项目下生成一个 `dist` 目录。

### 第四步：配置并启动服务
1. 修改 `config.json` 文件，填入你自定义的管理员密码与监听端口。
2. **（重要）在云服务器控制台安全组/防火墙中，放行对应的端口（如 8080）**。
3. 建议使用 `PM2` 进程管理器进行后台常驻运行，防止终端关闭后服务停止：
   * 安装 PM2：
     ```bash
     npm install -g pm2
     ```
   * 启动价格看板服务：
     ```bash
     pm2 start server.js --name danke-market-board
     ```
   * 查看状态/日志：
     ```bash
     pm2 status
     pm2 logs danke-market-board
     ```

## 📖 如何使用

### 1. 观众填报链接
观众直接访问你的域名或 IP：
```text
http://你的服务器IP:端口/
```
* **特点**：页面整洁，无“一键清空”或“一键排序”按钮。观众只能添加属于自己的价格，修改或删除时也仅对自己添加的行生效。他人提交的数据呈只读置灰状态。

### 2. 主播（管理员）链接
主播需要访问带 `?admin=密码` 参数的链接：
```text
http://你的服务器IP:端口/?admin=你的管理员密码
```
* **特点**：
  * 进入后页面顶部会显示 `👑 管理员模式`，密码会自动保存在浏览器缓存中（且 URL 中的敏感密码参数会被自动清除，防止直播时误露）。
  * 拥有全局删除、任意编辑、一键排序和一键清空的所有控制权。
  * 点击管理员状态旁的 `退出` 按钮即可切换回普通观众视角。
